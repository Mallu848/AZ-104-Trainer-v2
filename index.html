AZ-104 Exam Tips

🎯
Exam Format
  • 40–60 questions, 130 minutes
  • Passing score: 700/1000
  • Question types: MC, multi-select, drag-and-drop, case studies
  • No penalty for guessing — answer every question
  • You cannot go back after case studies
🔑
Identity & Governance (20–25%)
  • Know RBAC scope: MG → Sub → RG → Resource
  • Custom roles: Actions, NotActions, DataActions
  • Conditional Access: conditions → controls (grant/session)
  • Azure Policy: deny vs audit vs deployIfNotExists
  • CanNotDelete lock ≠ ReadOnly lock — know the difference
💾
Storage (15–20%)
  • Redundancy: LRS → ZRS → GRS → RA-GRS → GZRS → RA-GZRS
  • Blob tiers: Hot/Cool/Cold/Archive — access latency differences
  • SAS tokens: Service SAS vs Account SAS vs User Delegation SAS
  • Lifecycle management rules: target blob tiers by age
  • AzCopy is for large-scale transfers; Azure File Sync for hybrid
⚙️
Compute (20–25%)
  • Availability Sets: FD protects from rack failure, UD from updates
  • Availability Zones: physically separate data centers in a region
  • VMSS: auto-scales, uses health probes + scale rules
  • App Service slots: swap without downtime, warm up before swap
  • ARM templates are idempotent — safe to redeploy
🌐
Networking (15–20%)
  • VNet peering is non-transitive — hub-and-spoke needs UDRs
  • NSGs: stateful — allow inbound automatically allows return traffic
  • Service endpoints: secure Azure PaaS to your VNet subnet
  • Private endpoints: bring Azure PaaS into your VNet with private IP
  • Azure DNS private zones: link to VNet for resolution
📊
Monitor & Backup (10–15%)
  • Azure Monitor → Log Analytics → KQL queries
  • Diagnostic settings: route to Storage, Event Hub, or Log Analytics
  • VM Insights requires Log Analytics agent or AMA
  • Azure Backup: RSV must be in same region as the resource
  • Site Recovery: RPO in seconds, RTO minutes — not same as backup
⏱️
Test-Taking Strategy
  • Read the last sentence first — it tells you what's being asked
  • Eliminate answers with wrong service (e.g., wrong region constraint)
  • For "most cost-effective" — exclude premium SKUs unless required
  • For "least admin effort" — look for built-in policies and automations
  • Flag and return — use all 130 minutes
🧠
Common Traps
  • Storage account names: 3–24 chars, lowercase letters and numbers only
  • Azure AD Join vs Hybrid Join vs AD DS Join — not interchangeable
  • ReadOnly lock prevents tag changes too — not just deletes
  • RA-GRS read endpoint is always available, GRS is not
  • NSG on subnet AND NIC: both rules evaluated, most restrictive wins
